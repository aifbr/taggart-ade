# Marca Taggart

Trilho em perspectiva: a barra do T é o horizonte, os trilhos descem até quem olha e os dormentes em cobre marcam a profundidade.

| Arquivo | Uso |
| --- | --- |
| `taggart-icon-dark.svg` / `taggart-icon-light.svg` | ícone de app (squircle macOS) |
| `favicon.svg` | favicon e tamanhos até 32px (versão simplificada) |
| `taggart-mark-on-dark.svg` / `taggart-mark-on-light.svg` | marca solta, sem fundo |
| `taggart-lockup-on-dark.svg` / `taggart-lockup-on-light.svg` | marca + wordmark |

## Cores

| Token | Hex | Uso |
| --- | --- | --- |
| coal | `#151615` | fundo escuro |
| ink | `#e7e7e2` | marca e texto no escuro |
| paper | `#f7f5f0` | fundo claro |
| paper-ink | `#1d1e1d` | marca e texto no claro |
| copper-bright | `#d47a5a` | dormentes no escuro |
| copper-text | `#8b452f` | dormentes no claro |

Cobre só em detalhe (dormentes), nunca em grandes superfícies, como na marca AIFBR.

## Wordmark

`taggart` minúsculo em IBM Plex Mono 500. Os lockups usam `<text>`; converter para curvas antes de usar fora da web.
